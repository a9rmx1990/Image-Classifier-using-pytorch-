🧠 Image Classifier using PyTorch

A professional deep learning project repository focused on building, training, and experimenting with different neural network architectures on multiple image classification datasets using PyTorch.

This repository is designed as a long-term learning and research workspace for understanding deep learning fundamentals, computer vision workflows, model optimization, and practical AI system development.

📌 Project Objective

The primary goal of this repository is to explore and implement various image classification techniques while progressively learning:

Neural Network fundamentals
Deep Learning workflows
Computer Vision concepts
Model evaluation and optimization
Dataset preprocessing techniques
Modern deep learning architectures

The repository will continuously expand with new datasets, architectures, experiments, and deployment projects.

🚀 Current Implementation
✅ MNIST Handwritten Digit Classification

Implemented a neural network-based handwritten digit classifier using the MNIST dataset.
